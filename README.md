# Student Task Manager

## Project Description
Student Task Manager is a simple web application that helps students organize and manage their academic tasks. It is developed using HTML, CSS, and JavaScript.

## Features
- Add new tasks.
- Prevent empty task submission.
- View pending and completed tasks.
- Mark tasks as completed.
- Delete tasks.
- Responsive design for desktop and mobile devices.

## Technologies Used
- HTML – Creates the webpage structure.
- CSS – Styles the webpage and makes it responsive.
- JavaScript – Adds task management functionality.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Start adding and managing your tasks.
